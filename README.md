# 🚗 Otomoto Hybrid Bot

Telegram-бот, який кожні 15 хвилин переглядає нові оголошення на Otomoto
(Toyota Auris / Auris Touring Sports / Prius / Prius+ / Lexus CT та інші гібриди),
оцінює їх за нашими правилами і надсилає тобі повідомлення:

- 🔥 **ДЗВОНИ ВЖЕ** — проходить усі фільтри, хороша ціна, підходить тобі
- ⚠️ **ПІДОЗРІЛО ДЕШЕВО** — може бути вигідно, а може бути шахрайство
- 👀 **ГЛЯНЬ** — проходить фільтри, але є нюанси

У кожному повідомленні є ціна відносно ринку, плюси, мінуси і посилання.

> ⚠️ Чесно: Otomoto не має офіційного API, бот читає сторінки сайту.
> Якщо сайт змінить верстку або почне блокувати запити — бот напише тобі
> про це в Telegram, і парсер треба буде підправити.

## Налаштування (≈15 хвилин)

### 1. Створи Telegram-бота
1. У Telegram відкрий **@BotFather** → `/newbot` → придумай імʼя.
2. BotFather дасть **токен** вигляду `123456789:AAH...`. Збережи його.
3. Відкрий свого нового бота і натисни **Start** (інакше він не зможе тобі писати).

### 2. Дізнайся свій chat_id
1. Напиши своєму боту будь-яке повідомлення.
2. Відкрий у браузері (підстав свій токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. Знайди `"chat":{"id":123456789` — це число і є **chat_id**.

### 3. Створи репозиторій на GitHub
1. https://github.com/new → назва, наприклад, `otomoto-bot`.
2. **Public** (рекомендовано) — безлімітні хвилини GitHub Actions.
   У коді немає секретів, а файл `data/state.json` містить лише номери оголошень.
   Якщо хочеш **Private** — у `.github/workflows/watch.yml` зміни `*/15` на `*/30`,
   інакше вийдеш за безкоштовний ліміт (2000 хв/міс).
3. Завантаж усі файли цього проєкту (кнопка **Add file → Upload files**,
   перетягни вміст папки, разом із прихованою папкою `.github`).

### 4. Додай секрети
Repository → **Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_BOT_TOKEN` — токен з кроку 1
- `TELEGRAM_CHAT_ID` — число з кроку 2
- `HOME_ADDRESS` — твоя адреса для розрахунку відстані, наприклад
  `Floriańska 1, 31-019 Kraków` (впиши свою; номер квартири не потрібен)

**Надійніший варіант для адреси:** у Google Maps клацни правою кнопкою по своєму
будинку → скопіюй координати (наприклад `50.04xxx, 19.97xxx`) і додай два секрети
`HOME_LAT` і `HOME_LON` замість `HOME_ADDRESS`. Тоді не буде ризику, що безкоштовний
пошук адрес помилиться з будинком.

> 🔒 Адреса зберігається лише в секретах GitHub. У коді й файлах репозиторію її немає,
> тож навіть у публічному репозиторії її ніхто не побачить.

### Відстань до продавця
Бот рахує відстань **по дорогах, як навігатор** (кілометри й час їзди) від твого дому
до міста з оголошення — або до точки на карті, якщо Otomoto її показує.
За замовчуванням використовуються безкоштовні сервіси OpenStreetMap (Nominatim + OSRM).
Якщо хочеш саме **Google Maps** — створи ключ у Google Cloud (увімкни Geocoding API
і Distance Matrix API) і додай секрет `GOOGLE_MAPS_API_KEY`. Google дає безкоштовний
щомісячний ліміт, якого для бота з запасом вистачає, але вимагає привʼязати картку.

Оголошення далі ніж `FAR_DISTANCE_KM` (300 км, змінюється в `src/config.js`)
позначаються «⚠️ далеко».

### 5. Запусти
Repository → **Actions** → (якщо треба, натисни "I understand… enable") →
**Otomoto hybrid watcher** → **Run workflow**.

За хвилину-дві в Telegram прийде «🤖 Бот запущено…» і до 5 найкращих поточних оголошень.
Далі бот працює сам кожні ~15 хвилин і пише лише про **нові**.

## Налаштування фільтрів

Усе в `src/config.js`:
- `BUDGET` — максимальна ціна, пробіг, рік
- `SEARCHES` — які пошуки Otomoto переглядати
- `REFERENCE_PRICES` — орієнтовні ринкові ціни (мої оцінки, підправляй)
- `KEYWORDS` — слова-тригери в описах (таксі, ASO, тест батареї, LPG…)
- `NOTIFY_LOOK` — `false`, якщо хочеш лише 🔥 і ⚠️

## Запуск на своєму компʼютері (для перевірки або якщо GitHub блокують)
Потрібен Node.js 20.6+.
```bash
cp .env.example .env      # впиши токен і chat_id
npm run local             # реальний запуск
npm run dry               # без надсилання — повідомлення друкуються в консоль
npm test                  # тести правил оцінки
```

## Якщо щось не працює
- **«Не знайшов жодного оголошення»** — Otomoto змінив сайт. Збережи сторінку
  пошуку в браузері (Ctrl+S → «Веб-сторінка повністю») і виконай
  `npm run parse -- шлях/до/сторінки.html`. Результат надішли в чат — я поправлю парсер.
- **«Otomoto блокує запити»** — запускай рідше (`*/30`) або локально на ПК.
- **GitHub вимкнув розклад** — після 60 днів без активності в репозиторії GitHub
  може призупинити розклад; увімкни знову в Actions.
